# SEO Keyword Map

**Principle:** one primary keyword per URL, a cluster of secondary keywords, and no two pages competing for the same primary term.

For each page, the primary keyword goes in:
- the `<title>`
- the H1
- the first 100 words
- at least one H2
- the meta description
- internal-link anchors pointing to the page

Density comes from **covering the topic thoroughly**, not from repeating words. Keyword stuffing violates Google's spam policies.
